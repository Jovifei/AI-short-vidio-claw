## Prompt structure

1. State that supplied identity references are authoritative.
2. Describe only the scene/composition.
3. Describe visible action at one frozen moment.
4. Describe lighting/environment.
5. Repeat hard continuity items.
6. Add hard rejects.

## Required sentence

Use the supplied approved identity references as the source of truth. Preserve both characters' facial structure, species cues, hair/fur, ornaments and approved classical costumes. Do not reinterpret or modernize either character.
