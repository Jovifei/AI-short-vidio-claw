# 32 人物表演与 CP 互动圣经

状态：ACTIVE

## 1. 表演不是“摆 pose”

这套短剧要让观众觉得：
**摄影机碰巧拍到了他们的生活。**

所以表演重点是：
- 反应
- 等待
- 眼神
- 动作前后的小停顿
而不是连续大动作。

## 2. 林黛玉表演核心

### 外层
克制、安静、敏锐。

### 内层
很快注意到别人的细节，但不一定直接说。

### 常用微表情
- 眼睛先移过去，头不动
- 嘴角非常轻的笑
- 轻轻抿嘴
- 轻皱眉但不夸张
- 无语时停一秒
- 有点嫌弃的侧眼

### 禁止模板化
- 每镜皱眉
- 每镜低头
- 每镜歪头
- 每镜泪眼
- 永远病弱

### 身体语言
- 手势小
- 坐姿收束
- 站姿有古典仪态但不要僵
- 熟悉悟空以后可明显放松

## 3. 孙悟空表演核心

### 外层
快、直接、机灵。

### 内层
在黛玉面前会收住一点。

### 常用微表情
- 偷看
- 眉眼一挑
- 装作没事
- 被发现后快速移开视线
- 得意的小笑
- 疼但忍
- 保护时突然认真

### 猴脸原则
所有表情都必须建立在猴脸结构上。
不能为了“温柔”把五官软化成人类男脸。

### 身体语言
- 脚步比黛玉更快
- 坐姿更放松
- 手喜欢先动
- 发现黛玉不高兴会突然收敛

## 4. 两人关系节奏

### Phase A 熟悉
已同居，不需要演“刚恋爱”的拘谨。

### Phase B 互相吐槽
很多喜感来自：
- 她一个眼神
- 他自己收手
而不是台词解释。

### Phase C 保护
悟空的保护是动作性的。
黛玉的保护是细节性的。

### Phase D 宿命
第一季后段才逐渐出现。

## 5. CP 动作库

### Safe / M1
- 并肩坐
- 看同一个方向
- 偷看
- 递花
- 共享画面
- 轻靠肩
- 一人睡另一人不动
- 替对方留位置

### Medium / M2
- 牵手走
- 共伞
- 递物
- 扶肩
- 帮整理头发
- 并肩慢走

### High / M3
- 抱起
- 快速追闹
- 双手纠缠
- 亲吻全过程
- 复杂床上互动

M3 第一季可用静态 Hero Frame 表达。

## 6. 亲密度阶梯

L0 同框
L1 eye-line
L2 距离靠近
L3 轻触
L4 倚靠/牵手
L5 高接触

一集不需要从 L0 直接跳 L5。

## 7. EP001 情绪曲线

SH001–002：隐瞒 / 发现
SH003–005：照顾 / 逞强
SH006：偷看
SH007–010：恢复轻松
SH011–016：普通生活
SH017：安静
SH018–019：保护
SH020：无声回报

## 8. 生成 Prompt 表演词

推荐：
- restrained
- subtle
- familiar
- natural
- unposed
- candid
- small glance
- quiet reaction
- gentle pause

避免：
- passionately
- dramatically
- exaggerated
- ecstatic
- glamorous pose

这些词容易把生活短剧拉成海报/广告。
