# 28 人物建模板出图 Brief

目的：先让用户审核“人物到底长什么样”，再锁 Golden Model。

## 第一张：DAIYU Model Sheet

画面必须包含：
- 正面脸部
- 左 3/4
- 右 3/4
- 侧面
- 中性表情
- 微笑
- 轻微不悦/专注
- 半身
- OUTDOOR 全身
- HOME 全身
- 发式/发饰细节

审核重点：
- 下巴不是尖 V
- 脸不现代网红化
- 眼眉古典
- 发式稳定
- 两套古装仍是同一个人

## 第二张：WUKONG Model Sheet

画面必须包含：
- 正面猴脸
- 左/右 3/4
- 侧面
- 中性
- 轻笑
- 认真/疼痛
- 面颊毛区细节
- 耳形细节
- 头箍位置
- OUTDOOR 全身
- HOME 全身
- 尾巴与前臂毛发

审核重点：
- 不是男性脸加毛
- 眉骨/吻部/耳形固定
- 毛发分区固定
- 温柔表情仍像同一个经典猴王
- HOME stage 仍然是古装

## 第三张：Couple Scale Sheet

包含：
- 正面并肩全身
- 侧面并肩
- 坐姿
- 中近景对视
- 靠肩
- 同框但各做各的

用途：
- 锁身高差
- 锁头身比
- 锁肩宽
- 锁两人相互距离
- 证明同框时脸仍稳定
