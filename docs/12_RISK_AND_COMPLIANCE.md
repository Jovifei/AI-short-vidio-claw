# 12 风险、版权与合规

本文件不是法律意见，目的是给工程和内容生产设“不要踩线”的默认规则。

## 1. 古典人物与现代影视形象必须区分

林黛玉、孙悟空作为古典文学人物，其原始文学形象与现代影视作品中的：
- 演员脸；
- 妆造；
- 服装；
- 场景；
- 海报；
- 剧照；
- 台词改编；
不是同一个权利层面。

项目默认策略：
**使用古典人物概念，制作原创人物视觉，不复制具体影视改编。**

### 林黛玉
用户给出的影视/网络参考图可以帮助讨论“圆润鹅蛋脸、眼型、古典气质”等抽象方向，但不应把目标定义为“复刻某演员的脸”。

### 孙悟空
不要复制某一版电视剧/电影独有猴妆、服装、金箍、配色组合。

## 2. 角色 LoRA 数据

允许优先使用：
- 自己生成并拥有使用权的角色图；
- 明确授权素材；
- 公共领域素材。

避免：
- 批量抓取单个现代演员照片来训练角色 LoRA；
- 未授权影视截图数据集；
- 直接以真实演员 identity 作为商业角色资产。

## 3. 声音

GPT-SoVITS 能做 few-shot/zero-shot，不代表任何声音都可以克隆。

默认：
- 使用本人/授权配音；
- 使用明确可商用 voice asset；
- 不模仿知名演员或配音演员作为正式产品声音。

## 4. 开源代码许可证

当前已核验代码许可证：
- Story Claw：MIT
- Drama Skills：MIT
- PuLID：Apache-2.0
- Wan2.2：Apache-2.0
- FramePack：Apache-2.0
- MuseTalk：MIT
- GPT-SoVITS：MIT
- ComfyUI_IPAdapter_plus：GPL-3.0

注意：
“调用外部安装的 GPL 插件”和“复制/修改 GPL 代码后分发”有不同工程影响。项目默认不 vendor IPAdapter Plus 源码，保留为外部依赖。

## 5. 模型权重许可证

代码许可证 ≠ 权重许可证 ≠ 训练数据授权。

每个实际下载的权重必须单独在 model manifest 写：
- weight source；
- weight license；
- commercial use；
- attribution；
- restrictions。

没有确认前，不在文档里写“可商用”。

## 6. 第三方网页模型

ChatGPT 网页生成图片作为 Hero Lane 时：
- 记录生成日期；
- 保存原始输出；
- 不把他人受版权保护的剧照当成要求一比一复制的 target；
- 若后续商业化，重新确认当时服务条款和资产使用权。

## 7. 隐私与密钥

禁止 Git：
- API key
- cookie
- token
- 私有声音样本
- 未授权人像
- 本地绝对路径中的敏感个人信息

统一用 .env 和 local/。

## 8. 发布前 checklist

- [ ] 人物是否为原创设计而非具体演员复刻
- [ ] 声音是否有权使用
- [ ] BGM/SFX 是否有授权
- [ ] 模型权重是否允许目标用途
- [ ] 外部代码许可证义务是否履行
- [ ] 封面无第三方 Logo/商标误导
- [ ] 文案不暗示官方影视作品授权
- [ ] 如为二创/同人，平台标签和声明符合发布平台要求

## 9. 产品层风险

### 模型漂移
缓解：reference + LoRA + QC + accepted asset。

### 模型停更
缓解：adapter 化。

### 自定义节点崩坏
缓解：锁 commit、production/lab 分离。

### 12GB 性能不足
缓解：短镜、低分辨率、offload、FramePack、少量外部困难镜头。

### AI 过度自动化降低美术质量
缓解：Hero Lane 和人工 gate 永久保留。
