# 15 EP001 试播集计划（First Cut 风险收敛版）

## 标题
《大圣今天受伤了》

## 目标
先证明“20 张照片能讲完整故事”，再逐步把安全镜头动画化。

## 一句话故事
悟空受伤回家，黛玉嘴上嫌他逞能、手上一直照顾；第二天两人继续平常生活，雨夜回家时悟空把伞全偏给她。

## 目标时长
55–70 秒。

## 20 张 Story Keyframe

SH002 开门看见：黛玉先看他的手。MEDIUM。
SH003 “皮外伤”：医药箱入场。MEDIUM。
SH004 消毒：双人手部接触。HIGH / Hero。
SH005 包扎：手部特写。HIGH / Hero。
SH006 偷看：黛玉专注，悟空偷看。LOW-MEDIUM。
SH007 翻冰箱：冰箱视角。MEDIUM。
SH008 按回辣酱：手部交互。HIGH。
SH009 宵夜：同桌吃东西。MEDIUM。
SH010 洗碗泡沫：手+脸接触。HIGH。
SH011 刷牙：镜前同步。MEDIUM。
SH012 吹头发：工具+头发。MEDIUM-HIGH。
SH013 阳台浇花：水雾+双人。MEDIUM。
SH014 晒衣服：夹子/手。MEDIUM。
SH015 食堂夹菜：筷子/食物。HIGH。
SH016 买菜：人群+手持。MEDIUM。
SH017 公交回家：靠肩睡。LOW-MEDIUM。
SH018 下雨：出站/打伞。MEDIUM。
SH019 伞偏向她：雨+轻走。MEDIUM。

## P3 v0.1 动画只选 6 镜

第一批候选：
- SH001：轻走/镜头缓推
- SH006：呼吸 + 眼神
- SH007：冰箱灯/轻微伸手，动作失败可降为 camera push
- SH009：蒸汽 + 轻微视线，不要求复杂夹菜
- SH017：公交震动 + 呼吸 + 眨眼
- SH019：雨 + 伞轻摆 + 小幅位移；失败就静帧雨效

原则：
**动画镜头不是越多越好。先保证 First Cut 完成。**

## v0.1 静态/轻运动镜头

SH002/003/004/005/008/010/011/012/013/014/015/016/018/020 均允许：
- 静态 2–4 秒
- Ken Burns
- 景深变化
- 环境粒子
- 轻微灯光/雨/蒸汽
- 转场

高风险镜头不能因为“没真正 I2V”就判失败。

## First Cut Gate

观众在没有设定说明时能理解：
1. 悟空受伤；
2. 黛玉在照顾；
3. 两个人一起生活；
4. 第二天关系自然延续；
5. 雨夜有情绪收束。

First Cut 的成功不要求：
- 每张都动；
- 每句都口型；
- 手部交互全靠 I2V。
