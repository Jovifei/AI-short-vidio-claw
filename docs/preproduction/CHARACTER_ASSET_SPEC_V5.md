# V5｜角色、服装与素材资产规格

## 1. 四种“模型”严格分开

1. **二维设定板**：当前已有。可用于审脸、审服装，不保证每个小面板是几何一致的同一个三维头。
2. **二维单张参考/关键帧**：当前有候选与裁片；通过具体批准之后才可做生产输入。
3. **角色 LoRA**：当前没有已训练、验证的权重。本次没有创建 `.safetensors`，不能把 YAML 人物卡称为训练完成。
4. **三维人物模型**：当前没有拓扑、UV、骨骼、形态键与衣料绑定。不是当前 I2V 首片的前置条件。

## 2. 本轮真实资产清单

`generated_assets_v5.json` 中的17项全部有真实 SHA256、宽高、字节数和路径：3张人物/组合板、10张最近样图、4张精确裁片。

最新十张样图统一称 `REFBATCH02`，顺序为：山水牵手、草坡并坐、暮海双椅、花遮双眸、花路倒影、石阶相伴、心形吐司、草地墨镜、花束遮面、洗碗逗趣。

**它们不自动等于 LOOKREEL01 的 COMP01–COMP10。** LOOKREEL01 原计划包括夜景站姿、床边互动、相机、镜前抱起、枕头大战等。两批构图不能只按“第几张”覆盖，否则镜头计划会与文件内容错配。

## 3. 为什么只有四张裁片，而不是宣称三视图已完成

本轮裁片直接从1448×1086设定板截取，记录矩形坐标和父图hash。沒有补画未存在的角度。

- `DAIYU_FACE_CROP`：现有近景脸部；不是独立拍摄的标准正面。
- `WUKONG_FACE_CROP`：现有三分之四视角；不是“已批准侧面”。
- 两张 `*_COSTUME_CROP`：外出古装的全身区域，分辨率较低；适合确认层次与主色，不作细节训练数据。

后续补图采用“同一母版、单次只改变角度/表情”的办法。把大板重新放大不会增加真实脸部细节，不能替代新近景。

## 4. 脸部母版约束

### 黛玉

保留用户已反复要求的圆润偏鹅蛋轮廓、自然颏部、细眉与含蓄眼型。眼皮在光照下的视觉效果以批准图片为准；不把生成板上的“单眼皮”字样当作已经考证过的原著结论。下巴不能为了所谓上镜被削尖；也不能为了圆脸变成幼童比例。

脸部QA顺序：正面整体轮廓 → 下巴曲线 → 眼眉关系 → 鼻口体量 → 发际与鬓发。表情只允许改变肌肉姿态，不改变五官间距。前后图先同尺度对照再评分；不得用不同焦距造成的透视差误判成身份差。

### 悟空

保留母版中的眉骨、眼窝、口鼻过渡、面颊毛区、耳位和颏下毛。不要用“human face”整词作为双人镜头负向，因为同框还有黛玉；限制应针对悟空发生的人脸化。

微笑时仍然保持同一猴面，不因“恩爱”改成普通男子；不要增加没有参考依据的尾巴、巨猿吻部或狮子耳。

### 两人共同限制

角色用于本项目的成年人同人设定。不能从图片认定现实演员身份；项目中只用角色ID和参考ID。现有设定板的影视版本标题、文学句子、身高数字等不自动进入产品事实。

## 5. 服装阶段与“斗战胜佛装饰”

不是每镜叠满盔甲、长翎、佛冠、光环和念珠。先选择一致的组合，再按镜头引用。

| 阶段 | 保留 | 暂不加入/需要另审 |
|---|---|---|
| WUKONG_CLASSIC_OUTDOOR（alias DZS_DAILY） | 金黄/灰棕轻古装、固定念珠、批准轻冠或帽 | 日常不叠重肩甲；不随机切换冠帽，光环不作默认日常资产 |
| WUKONG_DZS_FORMAL | 明确选正式金红甲装、批准冠饰与护腕 | 仅COMP09等明确FORMAL镜头使用，不拿正式裁片冒充日常服装参考 |
| WUKONG_CLASSIC_HOME | 古装轻量内层、柔软领口、少量固定配饰 | 不穿现代背心；不戴尖锐肩甲做靠肩或床边动作 |
| WUKONG_CLASSIC_INJURED | 继承 HOME 外观，额外叠加左手背伤/绷带状态 | 伤是连续性状态，不是每镜换一套服装的理由 |
| DAIYU_CLASSIC_OUTDOOR | 淡紫/月白基色、多层衣料、固定花簪 | 不把每件小花饰随机替换为另一套 |
| DAIYU_CLASSIC_HOME | 同一色系、古典内衫、袖口便于家务 | 不用现代睡衣；“居家轻装”需具体图批准，文字本身不等于母版 |
| DAIYU_CLASSIC_RAIN | OUTDOOR 同一套衣服的湿度状态 | 不另长出披风、帽子或换发髻，除非镜头明确引入 |

当前注册的服装裁片分别覆盖黛玉外出、悟空FORMAL；悟空DAILY及双方HOME服装的清晰母版仍需要单独选择/生成并批准，不能用空ref或填写一个并不存在的ID强行过门禁。

## 7. 以后训练 LoRA 前的数据合同

先用获批图制作第一条片。确实需要降低手工出图成本时，才训练。数据集记录：asset_id、原图hash、裁切方式、角色、视角、表情、服装、遮挡、授权状态和分组split。

同一原图派生的多次裁切必须放同一训练/验证分组，不能一边训练一边测试造成虚高。墨镜、花束遮脸、亲密接触、满页设定板与文字区域不进入基础脸部验证集。验证集使用未参与训练的场景。训练成功也不能自动替代当前母版，仍需同一双人场景回归。

## 与并行V3服装基线对齐

`CLASSIC_*`兼容ID依现有alias文件解析，具体对照见51号整合说明。服装语义以V3 Canonical为准，具体镜头选择以V5 JSON为准，文件批准仍逐asset记录。
