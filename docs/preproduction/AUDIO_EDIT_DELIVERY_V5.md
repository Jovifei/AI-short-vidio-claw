# V5｜声音、剪辑和成片验收

## 1. 精确时间合同

EP001 固定为24fps、1440帧、60.000秒；LOOKREEL01为24fps、648帧、27.000秒。时间段采用 `[start_frame, start_frame + duration_frames)`，最后一镜结束恰等于总帧数。没有重叠转场；需要叠化时必须把重叠帧数纳入计划，不能无声缩短成片。

所有镜头详细时间码已在 `director_cards_v5.md`。源模型帧数、源容器fps和最终剪辑时长分开记录：49帧以24fps播放约2.0417秒；81帧约3.375秒。49帧不是四秒，更不是五秒。将49帧改写为12fps是减速，不是补出了新动作。

本次规划中的2.5–3秒动态镜头暂用81帧候选源，剪辑保留所需帧；是否能稳定运行仍待本机I2V验证。首次小样可单独用49帧、2秒的试验计划，不得拿短小样冒充满足正式时长。用插帧生成更多中间帧，不应被当成修复换脸的办法。

## 2. 三句对白：保持原剧本，不新增一堆解释

| ID | 角色 | 拟定起止 | 文本 | 表演 |
|---|---|---|---|---|
| VO01 | 悟空 | 6.000–8.250s | 皮外伤。 | 压低、嘴硬；不是喊口号 |
| VO02 | 黛玉 | 9.000–12.500s | 下次再逞能，我便不管你了。 | 轻声、稳、略嗔；不哭诉 |
| VO03 | 悟空 | 15.500–17.750s | 你每回都这么说。 | 带一点笑、收尾留气口 |

上述是剪辑设计窗口，不是已测得的配音长度。文件已写入 `audio_cues_v5.json` 和 `dialogue_v5.srt`。实际录音过长则调整剪辑窗口，不能裁掉尾字；不为塞台词改变人物口型到失真。

第一版全部画外音。没有录制的音频状态是NOT_RECORDED。后续可使用本人/授权声音或许可明确的TTS；本轮没有克隆演员声线，也不声称已经获得配乐权利。

## 3. 声音分轨与位置

目录：`local/production/EP001/audio/` 下分 `dialogue/ambience/sfx/music/mix/`。

各轨文件命名：`EP001_VO01_take01.wav`、`EP001_AMB_RAIN_EXT_take01.wav`。元数据记录来源、文件hash、采样率、声道、实际秒数、剪辑区间和使用条件。建议中间母轨统一48kHz WAV；这是本项目交付约定，不是所有原文件都必须重采样才可审听。

处理顺序：先对白清晰 → 再环境声衔接 → 再必要动作音 → 最后选配乐。视频没有口型也可通过反打、道具特写或背面承载画外音。

雨棚到街道让雨声提前约半秒进入；室内末镜削弱高频雨声以形成隔窗感觉。每次切环境都检查有无突兀底噪断裂。

内部混音目标暂定整片约−16 LUFS、真峰值不超过−1 dBTP，作为工作目标，不称为某发布平台强制标准。真正完成后测响度；不要把“运行了loudnorm”当作已达标，记录测量输出与二次处理结果。

## 4. 画面处理规则

- 原图保留不动，制作输入版只做显式裁切或等比例缩放/留边；禁止直接把928×1648或9:16拉伸成480×832。
- 480×832并非精确9:16。先预览裁切/留边后再批准该输入hash。文字、冠翎、发饰和脸都检查安全边界。
- 主体缓推建议总缩放不超过约3%，属于本项目保守创作参数，不是模型技术限制。
- 先出720×1280审片，最终1080×1920只表示画布，必要时放大但不宣称新增了原生细节。
- 首片硬切为主。所有转场、重采样、音频映射、字幕和压缩都留在可追溯的后期记录中。

## 5. 静态回退不是换素材

一个动态镜头两次不合格后，回到**该镜头同一张已批准关键帧**，按原计划持续时长做静帧/缓推。不得用“另一张更容易动的脸”替换，更不得将之前的地铁模板插入。回退必须写accepted decision，final报告统计I2V与STILL数量。

## 6. 必做检查

技术：分辨率、总帧数、平均/标称fps、音轨、可解码、无缺镜、没有错误路径或缺失文件。

视觉：三点抽帧至少首/中/尾，再补查所有遮挡与转头时刻；采样不覆盖的区间需完整播放。抽三帧不是已经证明全程无漂移。

叙事：不读说明能看出受伤、照顾、次日生活、雨中回报、末镜绷带闭环。

交付目录：`local/production/<PROJECT>/edit/review/` 与 `.../edit/final/` 分开。没有用户终审不可写FINAL_APPROVED。
