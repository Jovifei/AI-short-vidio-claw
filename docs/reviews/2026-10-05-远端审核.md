## 2. 冻结的技术路线

来源：`docs/17_TECH_ROUTE_REVALIDATION.md`、`docs/02_FEASIBILITY.md`、`docs/stages/P1A_WAN22_5B_BASELINE.md`。

1. 战略可行，和「今天就能按原文档生产」是两件事。`docs/02_FEASIBILITY.md` 写的是：项目战略可行（GO），当前机器尚未达到今天即可生产（Current Production NO-GO）。
2. 本机审核把 P1 收窄到：Wan2.2 TI2V-5B、单套 ComfyUI、不做 identity / TTS / lipsync。
3. 5B 是 12GB 上合理的第一件试跑物，但任何宽、高、帧数都必须本机实测。官方 standalone 720P 示例写至少 24GB；ComfyUI 官方教程同时写 5B 加 native offloading 应能放进 8GB。两条都留在记录里，不以其中一条代替实测。
4. 14B 退出 P1A。官方 I2V-A14B standalone 写至少 80GB。GGUF、block swap、Wrapper 都不进这一阶段。
5. P1A 的阶段目标只是证明原生 Wan2.2 5B 能在某一组本机参数上稳定跑 I2V。不是做 EP001，也不是把所有模型比一遍。
6. 建议阶梯是 L1 480×832 / 49 帧，L2 480×832 / 81 帧，L3 576×1024 / 49 帧，L4 576×1024 / 81 帧。每次只改一档。不靠改 steps / CFG 去掩盖 OOM。不并行。
7. P1A PASS 要同时满足：10 次里至少 9 次成功、无持续 OOM、metadata 完整、脚本能拿到输出、有本机 recommended baseline、有 p50/p95 和磁盘预算。十次连跑虽然 10/10 成功，但是文生视频，记录自己写了 `p1a_pass: false`。
